# 洗车小程序系统php+uniapp全开源

源码地址：ym7k.com/17823/

这套基于 PHP 后端搭配 Uniapp 前端的洗车小程序全开源系统，面向同城洗车门店、上门洗车服务商打造，覆盖车主端、商家核销端、后台管理端三大角色，把洗车消费、门店接单、会员营销、数据统计整套流程线上化，一套源码同时支持到店洗车与上门洗车两种业务模式，开箱即可部署落地，非常适合中小洗车门店、创业者搭建自有洗车服务平台。

在车主小程序端，整套功能围绕便捷下单体验设计。系统自带 LBS 定位能力，打开小程序就能自动匹配附近洗车门店或者在岗技师，地图上直观展示距离、价格、营业状态和当前排队情况，车主可以快速筛选基础洗车、精洗、内饰深度清洁、打蜡等不同服务项目。下单支持即时叫单和预约下单两种方式，用户可以选定合适时段，填写车辆信息、特殊清洁备注，系统自动锁定时段并推送消息提醒，避免到店长时间排队。车主可以在个人中心添加多台车辆档案，保存车牌、车型信息，后续下单无需重复填写。支付渠道齐全，支持微信支付、余额支付、卡券抵扣，订单全程可追踪，待接单、服务中、待验收、已完成等状态实时更新，服务结束后支持评价晒图，方便商家收集反馈。同时内置完整会员营销体系，包含储值赠送、次卡、月卡、限时优惠券、积分兑换等功能，次卡支持设置有效期，核销采用动态核销码，有效防止冒用，帮助门店锁定回头客。

商家端功能聚焦接单与现场管理。技师或者门店管理员可以在小程序接单、修改订单状态，到店客户出示核销码即可完成核验，快速启动服务。系统支持多门店、多技师账号分权管理，不同门店只能查看和处理属于自己的订单，方便连锁门店统一运营。商家能够自主上架、修改洗车套餐价格，设置不同车型差价，随时发布优惠券、调整次卡活动，查看当日接单量、待处理订单，接收用户预约提醒，不用再依靠微信消息零散接单，减少漏单、错单问题。

后台管理平台是整套系统的运营中枢，权限划分清晰，平台管理员拥有最高权限，可管理全部门店、用户、订单与营销活动。后台支持统一配置服务项目、价格体系、分销规则，所有订单数据、营收流水、会员消费记录自动汇总，生成可视化统计报表，包含每日营收、套餐销量、会员增长、核销记录等数据，运营者可以直观掌握经营情况。同时后台具备完整的用户管理、卡券管理、评价管理功能，支持审核用户评价、冻结违规卡券、导出营业报表。分销功能也是一大亮点，车主分享推广链接给好友，好友下单后分享者自动获得佣金，佣金可在后台设置比例，支持在线提现，助力门店低成本引流拓客。

作为全开源项目，PHP+Uniapp 架构具备良好的跨端特性，一套前端代码可以编译成微信小程序、H5 页面，适配不同流量入口。后端采用 PHP 开发，部署门槛低，二次拓展空间充足，开发者可以根据业务需求新增汽车保养、配件商城、自助洗车机联动等功能。整套系统打通了线上引流、预约下单、现场核销、会员留存、数据复盘闭环，摆脱传统洗车店依赖线下到店、手工记账的模式，降低门店运营成本。对于想要入局洗车服务行业的从业者来说，这套开源系统省去从零开发的成本，功能完整、业务贴合洗车行业，是搭建同城洗车服务平台性价比很高的选择。
